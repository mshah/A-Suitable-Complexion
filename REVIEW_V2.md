# A Suitable Complexion — Website Review Update (v2)

**Private review edition — not approved for public posting.**

## Drop-in install

Copy this entire `a-suitable-complexion` directory into `exhibitions/` inside your A-Thrice repo, replacing the earlier directory. Opening `exhibitions/a-suitable-complexion/index.html` will show the review site; there are **no dependencies or build steps**. Leave the parent A-Thrice homepage unchanged until ready to publish.

## Changes since v1

1. History: the full original advertising archive now appears directly below the `The history is not a single origin story` passage on `timeline.html`. The old `archive.html` redirects to the new anchor.
2. Commerce: original vertical-bars/loop graphics were replaced by the two supplied editorial PNG infographics. Both open their full-sized image if clicked; they can scroll within their container on a narrow phone.
3. Commerce essay: the analytical pull quote is now larger and in the sticky side column on desktop, reflowing below the essay on mobile.
4. Promise Machine: the evidence entries now show an original Seoul Secret campaign screenshot (as supplied), the supplied Hazeline Snow archive image URL, the higher-resolution GlutaMAX portrait ad, and the supplied Glow & Lovely promotional graphic.
5. Gallery: added a prominent interactive cue; the seven-shade key and filled/unfilled specimen already work in vanilla JavaScript.
6. All family gallery works remain placeholders. Only the preselected A-Thrice lyrics from `3 Migrations Deep` and `Faceprint` are in the website.
