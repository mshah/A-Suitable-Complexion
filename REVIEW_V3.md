# A Suitable Complexion — Gallery review update (V3)

**Private review — six provisional painting studies, not final or approved for publication.**

## Install
Extract the ZIP and replace the complete `exhibitions/a-suitable-complexion/` folder in your local A-Thrice repository. Open `index.html` and navigate to **The work**. No external libraries or build tools are needed. The main A-Thrice homepage is unchanged.

## What changed
- Replaced six abstract gallery placeholders with six exact supplied provisional image studies.
- Kept each image’s entire composition and its embedded complexion key in the gallery, without cropping or modifying the artwork.
- Added a keyboard-accessible large-image viewer, with next/previous buttons and Esc to close. With JavaScript disabled, the images still open as ordinary image links.
- Added compressed WEBP previews to keep gallery loading quick; the full-size original PNGs remain available inside the package and open in the viewer.
- Kept the interactive seven-colour key, essays, research, original adverts, and infographics from V2 unchanged.
- Updated banners and captions to state that family artwork studies are now visible, but not final.

## Publication note
These are not approved final artworks. The gallery intentionally uses generic artwork titles, not family names. Before the public release, review the final renderings against the series rules and secure any necessary permissions, especially where children appear.
